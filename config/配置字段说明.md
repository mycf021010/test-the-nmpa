# Python 配置逐项说明：Windows 开发与 Linux 部署

JSON 标准不支持 `//` 或 `#` 注释，因此注释放在本文件和读取配置的 Python 源码中。不要向 JSON 插入注释，否则会启动失败。

本机使用：复制 settings.local.example.json 为 settings.local.json。
Linux 使用：复制 settings.linux.example.json 为 settings.local.json，再填写实际路径、主机和密码。两个 example 都没有真实密码，不能直接作为完整配置运行。

| 字段 | 含义及迁移时要注意的地方 |
|---|---|
| api_key | Java → FastAPI 的接口密钥。与 Java 的 nmpa.collector.api-key 完全一致；不放前端；变更后同步两端并重启 API、Worker、Java。 |
| host | FastAPI 的监听地址。127.0.0.1 只允许本机连接；Linux 若由同机 Nginx 反向代理，可继续用它。若需要别的机器直接连接，监听具体网卡地址或 0.0.0.0，并配置对应访问范围。0.0.0.0 不是 Java 应填的调用地址。 |
| port | FastAPI 的内部监听端口，默认 8000。Nginx 可在外部用 HTTPS 443 转发到内部 8000，两者不是同一个端口。 |
| data_dir | 任务 SQLite、采集结果和备份的持久目录；API 和 Worker 必须相同。Linux 示例 /opt/nmpa-service-data 需要部署账号有读写权限；重启不能随意换目录。 |
| node_executable | Node 24 的命令或绝对路径。Windows 可以 node.exe，Linux 常用 node 或 /usr/bin/node，按实际安装确认。 |
| npm_executable | 首次安装 Node 依赖使用。Windows 可以 npm.cmd；Linux 为 npm 或实际完整路径。 |
| mysqldump | 备份工具位置。Windows 为 exe 完整路径；Linux 为 mysqldump 命令或 /usr/bin/mysqldump。必须实际安装。 |
| mysql.host | 从 Python 所在机器看数据库的地址。Python 搬到 Linux 后，127.0.0.1 指 Linux，而不是你的 Windows。 |
| mysql.port | 数据库监听端口，默认 3306。 |
| mysql.database | 原业务库 ak_medical；需确认部署环境确实有该库。 |
| mysql.username / password | MySQL 登录账号与密码，和 api_key 分开。MySQL 用户的允许主机要匹配 Python 连接来源。 |
| table | 业务表 t_medical_device；保持原有字段、InnoDB 和完整证号唯一索引。 |

Linux 示例中的 mysql.host=127.0.0.1 仅适用于 MySQL 也在那台 Linux 上。若 MySQL 是云数据库或另一台服务器，填实际内网数据库地址。若仍用 Windows 本地 MySQL，必须先建立服务器可访问的私有网络或隧道；直接写 Windows 的 192.168.x.x 地址不能从普通云服务器访问。此配置文件不会替你建立网络。

## 修改接口密钥

建议自行设置至少 32 个随机英文字母或数字，不使用中文密钥。开发环境和云端生产环境可以使用不同密钥，但 Java 必须填入它当前连接的那套 FastAPI 的密钥。先暂停新任务提交，同步保存两端配置，再重启 API、Worker、Java，最后在服务连接页确认鉴权正常。前端不用改，也不要把密钥放入浏览器链接。

## 配置优先级

程序默认读取 fastapi/config/settings.local.json；存在时，文件内明确填写的字段会覆盖同名环境变量。因此，Linux 上若用环境变量管理密钥，不能留下带旧 api_key 的本地 JSON。

可以设置 NMPA_SETTINGS_FILE 指向单独受控的配置文件，例如 /etc/nmpa/settings.json。该文件存在时仍采用同样的文件优先规则。若指定文件不存在，当前实现回退读取环境变量；生产部署要确认路径确实存在，避免误以为新文件已经生效。

如果只用环境变量，移走 settings.local.json，并在启动 API 和 Worker 的服务配置中设置同一组环境变量；程序不会自动读取名为 .env 的文件。

| 环境变量 | 对应配置 |
|---|---|
| NMPA_API_KEY | api_key |
| NMPA_HOST / NMPA_PORT | host / port |
| NMPA_DATA_DIR | data_dir |
| NMPA_NODE / NMPA_NPM | node_executable / npm_executable |
| NMPA_MYSQLDUMP | mysqldump |
| NMPA_DATABASE_URL | 完整数据库连接 URL；文件中有 mysql 对象时会被它覆盖。密码有特殊字符时优先用 JSON 的分开字段，避免 URL 转义错误。 |
| NMPA_TABLE | table |

当前网站 Java 配置在 backend/src/main/resources/application.yml 和 config/application-migration.yml。通过 NMPA_COLLECTOR_API_KEY 显式绑定 nmpa.collector.api-key；与 Python api_key 相同。启动前按包根目录 docs/01 加载 config/backend.env 或 backend.env.ps1；不要使用早期独立工作台的 NMPA_APIKEY/nmpa.api-key 配置。

Linux 配置文件含密码时只交给部署账号读取，不放在前端静态目录或公开下载目录。
